# Future improvements
Here is a list of future improvements who could be implemented:
1. **Linux Local Authentication** for account management actions enable local authentication for Linux, with user's password saved in the OS.
2. **Background execution** see if it's possible to implement multi-thread execution during background tasks. It would help the cloud import and export to perform faster.
3. **Database encryption for desktop apps** When the application is executed on a desktop device, data are not encrypted. Implement database encryption not only on mobile devices will help improve data security. When designing this functionalities, it is recommended to find a way to manage data encryption and decryption in a fast way, so as not to affect application performances too much. 
4. **Improve financial management** Give the user the chance to choose the currency and manage possible convertions.
5. **Multiple language support** The GUI is currently written in Italian. It would be a great step-forward at least to provide the english version, as well.
