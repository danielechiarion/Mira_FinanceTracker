Method to control if two dates have the right time difference, which means the final date has a distance from the first one equal or more than the long duration indicated

  • startDate starting date

Implementation

bool rightTimeDifference(DateTime startDate, DateTime endDate){
  /* first control if start date and end date given
  are correct */
  if(startDate.isAfter(endDate)){
    throw Exception("Start date can't be after the end date");
  }

  DateTime threshold = DateTime(
    startDate.year + years,
    startDate.month + months,
    startDate.day + days,
  );
  return !endDate.isBefore(threshold);
}
