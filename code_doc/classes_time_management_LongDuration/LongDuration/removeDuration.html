Remove another LongDuration from this instance, normalizing by borrowing from months/years when necessary so days >= 0 and months >= 0.

  • other duration to subtract Returns a new LongDuration with the resulting duration. Throws an Exception if the resulting duration would be negative.

Implementation

LongDuration removeDuration(LongDuration other) {
  int newDays = days - other.days;
  int newMonths = months - other.months;
  int newYears = years - other.years;

  while (newDays < 0) {
    newMonths--;
    newDays += 31;
  }

  while (newMonths < 0) {
    newYears--;
    newMonths += 12;
  }

  if (newYears < 0) {
    throw Exception("Resulting duration can't be negative");
  }

  return LongDuration(years: newYears, months: newMonths, days: newDays);
}
