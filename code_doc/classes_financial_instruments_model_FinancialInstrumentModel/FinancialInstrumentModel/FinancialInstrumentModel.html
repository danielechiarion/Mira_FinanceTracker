Constructor for a financial instrument model with all the necessary data to build it the right way

  • _name name of the financial instrument model
  • _providerType type of provider of the service (mainly private or public)
  • _duration duration of the financial instrument
  • _payoutFrequency frequency of paying out the interests
  • id ID of the database for the model saved (it will be -1 at the beginning)
  • description optional description for the financial instrument
  • provider optional provider of the service (mandatory if it's a private one)
  • taxRate tax rate applied to the interests earned from the financial instrument
