CloudBackupCleaner

CloudBackupCleaner class

Permanently removes all files and folders in the app's private Drive space.

Call init, then execute, and finally dispose. Ask the user for confirmation before calling execute, since the deletion cannot be undone. Backups created by older versions in the regular Drive space are not included.
