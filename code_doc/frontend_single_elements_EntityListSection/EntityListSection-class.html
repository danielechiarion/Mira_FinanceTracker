EntityListSection

EntityListSection<T> class

Embeddable, list-style management widget for a set of entities of type T: a search box, an "add" button, and a list of tiles with edit/delete actions. This is the reusable core behind EntityManagementPage - which wraps it in its own Scaffold/AppBar for full-page use - and can also be embedded directly inside another page's section (e.g. the "movimenti comuni" section of AccountTypePage).
