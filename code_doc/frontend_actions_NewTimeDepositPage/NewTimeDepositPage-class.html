NewTimeDepositPage

NewTimeDepositPage class

Page to actually subscribe a TimeDeposit on a savings account ("conto deposito"), built on top of ActionOperationPage just like PeriodicBillingFormPage: a single StatefulBuilder wraps the whole Form so every conditional field (account selected, model chosen, cashability, month of year, ...) can react locally without turning this widget itself into a StatefulWidget.

The user can either build the time deposit from scratch, filling in every financial condition by hand, or pick one of the saved TimeDepositModel. In the latter case every field the model already defines (provider, tax rate, interest rate, duration, payout frequency, cashability) is locked and shown as a read-only summary; only the instance-specific data (name, initial value, starting date, day/month of payout) stays editable, exactly as TimeDeposit.fromModel expects it.

ASSUMPTIONS MADE WHILE BUILDING THIS PAGE (please double-check them against the real project before wiring it up):

  • includeStart, includeEnd, lastDateActivity and currentValue are left to their defaults and not exposed here, to keep the form at the same level of detail as PeriodicBillingFormPage.
  • TimeDeposit requires an instrumentUsed value even when there's no model behind it (see TimeDeposit.fromModel passing model.name there): a placeholder string is used for the "from scratch" flow, marked below, since its exact intended semantics weren't clear from the files shared.
  • TimeDeposit.fromModel doesn't forward isCashable / earlyWithdrawalInterestRate from the model, so they're applied right after construction to fully honor the model chosen.
  • every call into UserDatabaseWrapper beyond the ones already used by FinancialInstituteManagementPage / FinancialInstrumentModelManagementPage is a guess at the actual method name and is marked with a "TODO".
