TimeDeposit

TimeDeposit class

Class to specify a particular type of financial instrument. Time deposits usually have a stable interest rate and a specified duration, with a payout frequency decided at the beginning. This services is one of the safest one to subscribe, manage and ensure interests that are low but secure.
