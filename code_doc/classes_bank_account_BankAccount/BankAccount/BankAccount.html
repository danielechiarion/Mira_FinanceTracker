Constructor method to build a bank account with it's basic functionalities

  • _name unique name given by the user to the bank account
  • _bank bank institute where the bank account belongs
  • _subscriptionDate date of the subscription of the bank account
  • id ID of the account from the database (it will be -1 right after the instantiation)
  • availableBalance it indicates how much money are available for the user
  • IBAN IBAN code of the bank account (optional)
  • interest possible interest applied to the availble balance of the bank account
  • active flag to understand if the user wants this bank account active or just archived
  • endingDate possible ending date of use of the bank account
  • fees list of fees of the bank account
  • cashbacks list of cashbacks of the bank account
  • transactions list of transactions of the bank account (not necessarily all of them)

Implementation

BankAccount(this._name, this._bank, this._subscriptionDate,
  {this._id = -1, this._availableBalance = 0.0, this._IBAN, this._interest = 0.0, this._active = true, this._endingDate, PeriodicAccountDuration? interestTime,
  List<BankFee>? fees, List<Cashback>? cashbacks, List<BankTransaction>? transactions}){
  /* control validity of the attributes first */
  if(_subscriptionDate.isAfter(DateTime.now())){
    throw Exception("In a bank account the subscription date must come before the current datetime");
  }
  if(_endingDate != null && !_endingDate!.isAfter(_subscriptionDate)){
    throw Exception("In a bank account the subscription date must come before the ending date");
  }
  if(_interest < 0){
    throw Exception("In a bank account the possible interest applied must be 0% or more.");
  }

  /* populate the lists */
  _fees = fees?.toSet() ?? {};
  _cashbacks = cashbacks?.toSet() ?? {};
  _transactions = transactions?.toSet() ?? {};

  /* then populate the interest time
  with day of the month corresponding to the one of the subscription date */
  _interestTime = interestTime ?? PeriodicAccountDuration(_subscriptionDate, DurationType.monthly, _subscriptionDate.day);
}
