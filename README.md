**Mira Finance Tracker** offers a new way of managing bank accounts and transactions, with interactive charts all together.  
It is a cross-platform application that lets you register and control bank transactions of different types, across multiple bank accounts and financial institutes, giving you a broader view of your total resources.

> ⚠️ *This application is only meant to register and control bank transactions. It cannot replace the original banking application used to make transactions, and it is not connected to your bank account: transactions are registered manually, sometimes with automatic calculation.*

---

## ✨ Key Features

| | Feature | Description |
|---|---|---|
| 👥 | **Multi-account support** | Manage multiple users on the same device, each with their own encrypted database. |
| 🏦 | **All bank account types** | Current accounts, savings accounts, and payment cards (debit/prepaid and credit). |
| 📈 | **Financial instruments** | Time deposits, bonds, and stocks, with dynamic interest calculation. |
| 📊 | **Interactive charts** | Monthly status, patrimony distribution, and recent trends on the home page. |
| ⚙️ | **Background tasks** | Automatic calculation of periodic incomes, domiciliations, cashbacks, and bank fees. |
| ☁️ | **Cloud backup** | Optional synchronization between devices via Google Drive, with end-to-end encryption. |
| 🔐 | **Security first** | AES-256-GCM encryption, local authentication (device PIN, fingerprint, Face ID), and a user passkey for cloud recovery. |
